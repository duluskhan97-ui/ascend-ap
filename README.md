# ASCEND PWA MVP 0.1

Русскоязычная устанавливаемая веб-версия RPG-трекера ASCEND. Работает на iPhone в Safari, сохраняет прогресс локально и поддерживает офлайн-кэш после первого открытия по HTTPS.

## Что есть
- Персонаж, общий уровень и XP
- INT / STR / AGI / END: отдельные уровни и опыт
- Ранги E, D, C, B, A, S и титулы
- Ежедневные квесты и каталог испытаний
- Простейшая адаптация выбора заданий по отстающим характеристикам и истории
- История, достижения, серии дней
- Экспорт и импорт локального сохранения
- PWA manifest, service worker, иконки

## Установка на iPhone
PWA требует HTTPS-хостинг; открыть скачанный HTML-файл напрямую недостаточно для полной установки.
1. Разместите все файлы этой папки на статическом HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте опубликованный URL в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите ASCEND с домашнего экрана. После первого онлайн-открытия основные файлы кэшируются для офлайн-запуска.

## Примечание
Прогресс хранится в localStorage конкретного браузера/установки. Экспортируйте резервную копию в разделе «Профиль» перед очисткой данных Safari. Это MVP без аккаунтов и облачной синхронизации.
